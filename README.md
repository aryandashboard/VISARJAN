# VISARJAN — Don't Let the Light Go Out

A 2D arcade survival/exploration game inspired by Ganesh Chaturthi.

## Game Objective

Guide Mushak through Bappa's final journey while protecting a sacred diya flame.

Collect oil and diyas, increase devotion through flowers, avoid obstacles, survive changing weather, and reach Visarjan.

## Controls

| Key | Action |
|---|---|
| A / ← | Move left |
| D / → | Move right |
| Space / W / ↑ | Jump |
| Shift | Dash |

Important:
The player controls all horizontal movement.
There is NO automatic running.

## Gameplay

- Keep the flame alive
- Collect oil
- Collect diyas
- Collect flowers
- Build devotion
- Activate Bappa Blessing
- Jump over obstacles
- Survive weather
- Reach Visarjan

## Tech Stack

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- Web Audio API
- LocalStorage

No backend required.

## How to Run

Simply open:

`index.html`

in a modern browser.

Recommended:
Chrome / Edge / Firefox.

## Project Structure

- `index.html`: Main game entry point and UI layout.
- `style.css`: Styles for the UI, HUD, and menus.
- `js/main.js`: Core game loop, state management, and input handling.
- `js/player.js`: Mushak's physics, jumping, and movement logic.
- `js/entities.js`: Obstacle and collectible management, collision detection.
- `js/flame.js`: Flame state, devotion tracker, and lighting effects.
- `js/environment.js`: Parallax backgrounds and weather effects.
- `js/particles.js`: Visual particle effects for interactions and weather.
- `js/audio.js`: Synthesized Web Audio API sound effects.
- `js/ui.js`: HUD rendering and screen transitions.
